# BALANCE / PROGRESSION

## Early game goals
Первые 15 минут:
- пройти tutorial run;
- получить 1-3 Brainrots;
- поставить 2 на farm;
- собрать первые Coins;
- купить первый upgrade;
- увидеть Rare как достижимую цель.

## Example Brainrot base production
Common: 10-18/min
Uncommon: 18-30/min
Rare: 35-60/min
Epic: 75-120/min
Mythic: 160-260/min

Это ranges, не гарантированные множители.

## Upgrade pricing philosophy
Цена следующего значимого апгрейда должна измеряться несколькими короткими сессиями, а не минутами AFK.

## Run reward distribution
Не делать Mythic чисто "0.1% lucky roll" в core MVP. Mythic должен быть достижим через успешное прохождение полной риск-цепочки. Внутри tier можно случайно выбрать конкретного Brainrot из pool того же tier.

## Difficulty scaling
Stage 1: 90%+ новых игроков должны понять задачу.
Stage 2: лёгкая потеря времени/ошибка.
Stage 3: нужна концентрация.
Stage 4: нужна координация.
Stage 5: high tension, но outcome зависит от skill, а не только RNG.

## Duplicates
Duplicate должен оставаться полезным через farm production. Не вводить ранний recycle, который заставляет новичка разбираться в лишней системе.

## Inflation controls
- offline cap;
- rising slot prices;
- production upgrade curve;
- cosmetic sinks;
- no unlimited exponential multipliers;
- production definitions server-configured.

## Metrics to instrument
- run start/completion rate;
- Claim vs Upgrade by stage;
- failure rate by room/tier;
- time to first Brainrot;
- time to first farm placement;
- coins earned/spent;
- slot unlock timing;
- collection completion;
- session length;
- return rate.
