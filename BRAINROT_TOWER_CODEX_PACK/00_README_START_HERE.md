# BRAINROT TOWER - CODEX PACK

Этот пакет - рабочая инструкция для поэтапной разработки Roblox-игры через Codex.

## Концепт в одном абзаце

1-6 игроков заходят в короткие кооперативные забеги по "Башне хаоса". За прохождение комнат команда получает **Pending Brainrot** - ещё не закреплённую награду. После каждого успешного этапа игрок/команда выбирает: **CLAIM** (забрать текущего Brainrot навсегда) или **RISK / UPGRADE** (перейти в более сложную комнату ради более высокой редкости). Если следующая комната провалена, теряется только незакреплённая награда текущей цепочки; уже принадлежащие игроку Brainrots не ставятся и не теряются. После получения Brainrot его можно поставить на слот в своей **Brainrot Farm/Base**, где он пассивно производит Coins. Coins тратятся на гарантированные апгрейды базы, слотов, производства и удобства.

## Как пользоваться пакетом

1. Положи все `.md` файлы рядом с репозиторием/проектом, чтобы Codex мог их читать.
2. Первым сообщением дай Codex файл `13_FIRST_MESSAGE_TO_CODEX.md`.
3. Затем выполняй только один этап из `09_CODEX_STEP_BY_STEP_PROMPTS.md` за раз.
4. После каждого этапа запускай игру в Roblox Studio и проходи соответствующий блок из `10_ACCEPTANCE_CHECKLIST.md`.
5. Если этап не проходит чек-лист - не переходи дальше. Используй `12_BUGFIX_PROMPT_TEMPLATE.md`.
6. Не проси Codex "сделать всю игру" одним запросом. Этот проект специально разбит на вертикальные срезы.

## MVP

Сначала должны работать:
- 1-6 игроков;
- lobby + personal farm plot;
- 1 этаж/зона забега;
- 3 challenge rooms;
- Pending Reward + Claim/Upgrade;
- 5 rarity tiers;
- получение Brainrot в permanent inventory;
- размещение Brainrot на farm slot;
- пассивная генерация Coins;
- 4 deterministic upgrades;
- сохранение коллекции/фермы/Coins;
- серверная валидация;
- базовый HUD и результаты.

Только после стабильного MVP добавлять больше существ, комнат, этажей, мутаций, cosmetics и social features.
